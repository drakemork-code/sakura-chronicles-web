Crea una página web completa para Sakura Chronicles (sakurachronicles.lat), un MMORPG para PC y Android y ios con estética del juego actual

IMPORTANTE:
- El diseño debe parecer hecho por un diseñador profesional, no por una IA.
- Evita textos genéricos, tarjetas repetidas y secciones vacías.
- Usa una combinación de tipografías elegante y única, como Cinzel para títulos, Inter para textos y Marcellus para subtítulos.
- Mantén una identidad visual consistente con tonos rosa sakura, blanco, negro y detalles dorados.
- Añade sombras suaves, efectos hover y transiciones modernas.
- No utilices iconos ni imágenes de stock con apariencia artificial.

La web debe incluir:

1. Página principal
- Banner con logo de Sakura Chronicles.
- Eslogan épico.
- Botón "Jugar Ahora".
- Botones de descarga para Android y Windows y ios
- videos del juego.
- Capturas del juego.
- Noticias recientes.

2. Sistema de noticias
- Artículos con fecha y autor.
- Diseño similar a páginas de MMORPG profesionales.

3. Página de descargas
- Última versión disponible.
- Historial de versiones.
- Changelog organizado.
- Descarga para Android y PC.

4. Página de cuenta
- Registro.
- Inicio de sesión.
- Recuperación de contraseña.

5. Estado del servidor
- Online/Offline.
- Jugadores conectados.
- Ping y tiempo activo.

6. Wiki
- Clases.
- Armas.
- Profesiones.
- Jefes.
- Mazmorras.

7. Footer
- Discord.
- Facebook.
- Términos y condiciones.
- Política de privacidad.

Aspecto visual:
- Inspirado en sitios oficiales de MMORPG como  world of warcraft Final Fantasy XIV.
- Diseño responsive para móviles y PC.
- Animaciones fluidas y elegantes.
- Evita componentes repetitivos y layouts típicos generados por IA.
- Cada sección debe tener una composición única y bien equilibrada.
- Las imágenes deben tener marcos decorativos inspirados en flores de cerezo y fantasía japonesa.

Código limpio y modular.
Utiliza HTML5, CSS moderno y JavaScript.
Organiza los archivos correctamente.
Incluye comentarios en el código.
No coloques textos de ejemplo tipo Lorem Ipsum.
Genera contenido coherente y natural en español.
Haz que la web parezca la página oficial de un MMORPG comercial.
